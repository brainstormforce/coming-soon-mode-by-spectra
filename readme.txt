Coming Soon Mode By Spectra is a lightweight plugin for activating Coming Soon or Maintenance mode on your website.

== Description ==

Coming Soon Mode By Spectra is a standalone dedicated plugin for applying Coming soon mode and maintenance mode on your website without installing any other plugin or interfering with code. Make your website inaccessible to the public with our simple and easy-to-use Coming soon mode.

It is very lightweight (less than 5KB on the frontend side) and optimized for speed. The plugin UI is extremely clean and looks professional.

= Features =

* Compatible with any WordPress theme
* Live mode is accessible only to the selected user or logged-in user as per setting selection
* Multiselect Page even when coming soon mode is active
* Control Header, Footer & Sidebar appearance of your selected page
* Built-in Coming Soon templates for quick start
* Optional signup template collects visitor emails for launch notifications
* Modern React-based admin interface
* Lightweight and fast performance

== Installation ==

= From within WordPress =
1. Visit "Plugins > Add New"
2. Search for "Coming Soon Mode By Spectra"
3. Install and activate the plugin

= Manual Installation =
1. Upload the entire `coming-soon-mode-by-spectra` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to Settings > Coming Soon Mode to configure the plugin

== Frequently Asked Questions ==

= I have activated the plugin, but it seems the plugin is not working. =

After activating the plugin, make sure the plugin is activated by checking the setting page of the plugin. If it's still not working, try clearing your browser cache. If you continue to experience issues, please contact our support team.

= Is this plugin free? =

Yes, absolutely. This plugin is completely free to use.

= How do I set up the Coming Soon mode? =

1. Go to Settings > Coming Soon Mode
2. Select "Coming Soon" mode
3. Choose a page to display to visitors
4. Configure who can access the live site
5. Save your settings

= Can I allow certain users to see the live site? =

Yes, you can choose to allow all logged-in users to see the live site, or you can select specific user roles that should have access.

= Can I exclude certain pages from Coming Soon mode? =

Yes, you can select multiple pages that will remain accessible even when Coming Soon mode is active.
